# 网站重构修改说明

> 课程：《可视化导论》　|　原站：<https://cinger007.github.io/vis/>　|　重构方式：在保留全部教学内容的前提下**完全重构**，并把 27 个演示全部重新设计。
>
> 重构目标：**让内容展现更清晰、更适合学习，并增加可视化图形**。严格遵守"不嵌入视频（实时交互动画允许）、控制体积"的要求。

---

## 一、重构思路（一句话）

把原站"每章一个独立 HTML、结构深浅不一、演示多为静态/文本"的形态，重构为**一个数据驱动的课程系统**：一个章节模板驱动五章、讲解/代码/演示三视图统一、中英双语单一数据源、27 个演示全部可交互且按需懒加载，再补上知识地图、学习进度、全站检索、章末小结、速查、自测等学习辅助。

---

## 二、信息结构与导航的调整

| 方面 | 原站 | 重构后 | 作用 |
| --- | --- | --- | --- |
| 页面组织 | 每章一个独立 HTML，结构、样式、交互各不相同 | 统一 `chapter.html` 模板 + 五章内容数据（`ch01.js…ch05.js`） | 结构一致，学习路径可预期；新增章节只需加数据 |
| 正文层级 | 层级偏深，含"原案例"等多层栏目 | 精简为 5 个小节，**删除"原案例"栏目**（其有用内容并入正文/提示，不丢教学点） | 减少阅读负担，主线清晰 |
| 每节视图 | 讲解、代码、演示分散 | 每节统一 **讲解 / 关键代码 / 演示 三标签**，就地切换 | 原理、代码、效果来回对照，学习闭环 |
| 首页 | 简单入口 | Hero + 五章卡片 + 关键数据（5 章 / 27 交互演示 / 53 关键点） | 一眼看清课程全貌 |
| 知识地图 | 无 | 新增概念知识地图 | 建立概念间的整体关联 |
| 全站检索 | 无 | 新增关键词检索（标题/正文/概念） | 快速定位知识点 |
| 学习进度 | 无 | 新增进度记录与"清空进度"（本地存储） | 标记已学、持续学习 |
| 章末 | 无 | 新增**本章小结（5 条）、速查卡（5 条）、自测题（5 题，含参考答案）** | 复盘、临考速查、自我检验 |
| 语言 | 以中文为主 | 中英双语，一键切换（中/EN） | 兼顾中英文术语与双语教学 |
| 视觉 | 各章风格不统一 | 设计令牌（token）体系 + 每章识别色（数据靛蓝 / 流程青 / 色彩品红 / 低维蓝绿 / 时序琥珀） | 统一而有区分度 |
| 适配 | 主要面向桌面 | 响应式，桌面与窄屏（500px 手机）均可用 | 手机也能学习 |
| 代码 | 普通片段 | 语法高亮 + 一键复制 + 关键注释（why / warn） | 读代码、抄代码更方便 |

### 形式差异归纳
- **静态图 → 过程动画**：数据加载、DIKW、树布局、等值线、冒泡等都改成"逐步播放"。
- **文本/控制台 → 图形**：rollup 的 Map、数组函数的 JSON、宽长表的 JSON 都变成图形。
- **固定图 → 可搭建/可实验**：视觉通道、颜色模型、倾角、标量场都可亲手操作。
- **单图切换 → 小倍数同屏对比**：曲线、日历布局、配色方案同屏对比。
- **点选卡片 → 游戏化/主动诊断**：找茬闯关、拖拽分类、实时滤镜并修复。
- **新增图种**：treemap、pack 圆、马赛克、力导向聚簇、HSL 色轮、brush 联动、Alluvial 带等。
- **保留但换骨**：日历热图、螺旋、Storyline 等"教学点本身就是它"的图保留，改交互与对比方式。

## 四、技术与工程

- **纯静态、零构建**：HTML + CSS + 原生 ES Modules，无需打包/后端，直接放到 GitHub Pages 即可运行。
- **D3 v7 走 jsDelivr CDN**：`https://cdn.jsdelivr.net/npm/d3@7/+esm`；**d05-5 的 Alluvial 为手写，未额外引入 d3-sankey**，零额外依赖。
- **演示懒加载**：只在打开某节"演示"标签时才动态加载对应脚本，首屏更快。
- **全相对路径**：可部署到任意 `用户名.github.io/仓库名/` 子路径，无需改代码。
- **不嵌入任何视频/音频文件**：动态效果全部由 D3/SVG 实时计算，体积小、服务器零存储压力。
- **体积**：整站约 500 KB（含全部代码、数据、文档，无图片/视频大文件）。
- **数据**：复用原站数据集（newstudent、crime、french_names、weather_2024、storyline、time-attributes 等），未新增大文件。
- **可访问性**：支持 `prefers-reduced-motion`（开了"减少动态"则直接呈现静态首帧）、键盘可达、对比色规范。

## 六、视觉设计系统统一（风格专项优化）

在功能完成后，按 UI 设计方法论对全站做了一次**视觉系统统一**，重点是**比例与布局**，并把组件、按钮、图表、卡片、标签的颜色与风格收敛到同一套规则，使页面更适合课堂投影与教学。

### 1. 中性色：微染冷调的 Cool Slate，杜绝纯白纯黑
- 页面底由原先的近白 Tailwind slate 改为**微染冷色的中性阶**（`#eef1f5` 页面底 + 白卡 `#ffffff` 浮于其上），白是"构图元素"而非底色；正文/标题用三级墨色（`#14171c / #333a46 / #566175`），层次靠明度而非堆色。
- 分隔线统一为**半透明发丝线**（`rgba(20,27,38,.09)`），不再用硬灰描边；代码面板、页脚改用冷炭深底（`#131824`）而非纯黑。

### 2. 单主色 + 五章身份色，分工明确
- 全站只有一个**操作主色（靛 `#4a46c9`）**：主按钮、当前导航、语言激活、焦点环；功能反馈色（成功绿 / 警示琥珀 / 错误红 / 信息蓝）只承担语义，不与身份色混用。
- 五章身份色做了**碰撞校验后的降饱和重调**（数据靛 / 流程天空 / 色彩品红 / 低维青 / 时序焦赭），白字可读性达标；每章自动注入"主色 / 软底 / 描边 / 光晕"四件套，`meta.js` 与各演示主色同步。

### 3. 比例与布局：字阶断崖 + 圆角角色 + 一致栅格
- **字阶重排**：引入独立的展示字体（Sora，配 Noto Sans SC / JetBrains Mono），标题字号做明确"断崖"（展示标题 clamp 自适应、正文 15.5px），标题不再是"大一号的正文"；坐标轴与数字用等宽字体。
- **圆角分三角色**：控件 8px / 卡片 12px / 大壳 18px，pill 仅用于可点的小标签与开关；原先偏大的 14/20px 收窄，全站更克制、更技术化。
- **布局留白重排**：导航加高到 64px、章节侧栏 272px、版心 1200px、正文限制在舒适行宽（约 66ch）；首页章节卡由"2+2+1 末行孤卡"改为 **3+2 的 bento 栅格**，四个"使用方式"卡、关于区均做满格平衡，消除孤卡与大片空区。
- 统一按钮（主按钮实色投影 / 幽灵按钮白底描边）、分段 Tab（灰色轨道 + 实色激活段）、教学块、表格（斑马纹 + 表头）、代码块、分页卡、检索浮层、页脚的圆角、间距与投影。

### 4. 阴影与图表风格
- 所有投影改为**多层、带冷色底相**的组合（替代单层纯黑影），主操作使用同色投影。
- 27 个演示内部的坐标轴、网格、面板、标签灰阶与分类色板统一对齐到新令牌（d01/d02/d04/d05 共 160 余处）；d03 色彩章因本身在讲授颜色空间与 colormap，其教学语义色保留不动。
- 演示按钮由"全胶囊"改为与站点一致的控件圆角，正确/错误、聚焦、悬停等状态统一到语义色。

### 5. 验证
- 桌面 1440、窄屏 390、中英文双语，以及首页、章节三视图、27 个演示均做了两轮"截图—修改—再截图"回归；未改动任何教学内容、交互逻辑与数据。
- 字体走自托管镜像（Google Fonts 在国内不可达），并保留完整系统字体回退；字体加载失败时页面仍完整可读。

## 七、证据驱动的 UI 精修（审计 → 64 案例 → 像素规范 → 实施 → 复验）

在视觉系统统一的基础上，又按「现状审计 → 64 个优秀网页案例调研 → 16 条设计准则 → 像素级规范 → 改代码 → 两轮浏览器复验」做了一次专项精修，完整过程文档见 `docs/ui-optimization/01~05`。核心是**移动端可读性、布局比例、组件状态与设计一致性**：

- **宽表不再竖排单字**：章节内表格统一包进 `.tbl-scroll` 横向滚动容器（表保底 560px、表头不换行），390 手机上不再出现"准确性 / 完整性"逐字竖排；横滚被限制在表格内部，不会把整页撑宽。
- **三视图 Tab 永远保留文字**：删除旧版"≤440px 仅显示图标"的逻辑，窄屏改为图标在上、文字在下的三栏等宽按钮（高 48px），讲解 / 关键代码 / 演示三个含义不再丢失。
- **宽 SVG 窄屏保底可读**：d03 三面板色空间、d04 标尺三层、d05 Storyline / 日历等固定宽图，在窄屏以 760–920px 的保底宽度横向滚动，坐标轴与标注维持原字号，不再整体缩成 100px 不可读；桌面仍正常铺满。
- **触控与控件**：按钮 / 滑块 / 下拉的热区统一到 ≥42–48px，原生滑块、下拉跟随章节主色；补齐 hover / focus / active 等状态与焦点环。
- **首页比例**：知识地图 viewBox 由 1000×430 收紧到 1000×266，消除上下约 100/120px 的空带；区块间距令牌化（80px）并补一行引导句；卡片静态去除阴影、仅 hover 上浮，靠明度与 1px 边框分层。
- **响应式与可访问性**：统一 1023px 侧栏折叠断点，单栏列改 `minmax(0,1fr)` 根治宽表撑爆视口；覆盖 390/768/1024/1440/1920 五个断点，保留焦点环与 reduced-motion。
- **复验**：CDP 精确视口逐屏截图，390 章节页 `scrollWidth` 由 628 修正为 390；27 个演示经脚本逐例自动核验全部成功渲染、0 异常；未改动任何教学内容、数据与交互逻辑，未引入新依赖、未嵌入视频。
