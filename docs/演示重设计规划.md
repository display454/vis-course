## 1. 设计原则（差异化的统一打法）

1. **从"图 + 说明文字"变成"可操作的实验"**：原站几乎每个演示都是"一张静态图 + 控件 + 一段『⭐关键点』文字"。新演示让学生**操作后自己看到现象**，结论用一行字点出，长解释挪到讲解视图。
2. **换一种图表隐喻**：原站重复出现的形式（竖条、色板、静态流程图、水平树、文本控制台、卡片点选）**每个只保留一次以内**，其余替换为原站没有的形式（力导向、桑基、树图、马赛克、小倍数、色轮、brush、分步动画、拖拽配对、游戏化闯关）。
3. **真实数据贯穿**：尽量用课程自带数据（学生 `newstudent.csv` 80 条、犯罪 `crime.csv` 50 州、天气 `weather_2024.csv` 全年、法国人名 `french_names.json`），少用假数据；让不同章共用同一批数据，形成"同一数据、不同看法"的连贯感。
4. **动画服务理解**：用进入/转换动画演示"数据怎么变成图"（聚合、重排、绑定、冒泡），但**不堆特效**，且尊重 `prefers-reduced-motion`，提供"播放/暂停/单步"。
5. **对比即教学**：对错（配色/编码/坐标/螺旋）一律做**同屏前后对比或小倍数**，比单图 + 文字更有说服力——这本身也是课程想教的"小倍数/联动"方法。
6. **每个演示有明确的"成功反应"**：学生操作后图必须给出可被看见的反馈（聚簇、连线、评分、预警、路径高亮、误差曲线）。

## 2. 统一技术与交互规范

- **零构建、ES Modules、D3 v7 走 CDN**（`cdn.jsdelivr.net/npm/d3@7/+esm`，不占仓库空间）。
- 额外需要的非内置模块仍走 CDN：`d3-sankey`（`.../d3-sankey@0.12/+esm`，仅 5.5 用到）。其余如 `d3-force / d3-hierarchy(treemap/pack/cluster) / d3-chord / d3-brush / d3-contour / d3-drag / d3-zoom` 都已包含在 d3 全量包内。
- 沿用现有演示契约：`export default { 'd0X-N': async (mount, ctx) => {} }`，`ctx = { d3, data }`，演示懒加载。
- 演示**容器自适应宽度**：内部用 `viewBox` + `preserveAspectRatio`，宽度跟随 `.demo-card`；小屏横向滚动兜底。
- 所有 hover 都给**触摸等价路径**（点击/拖滑块）；可点区域 ≥ 44×44。
- 统一三态：加载中（骨架/进度）、空/出错（友好提示）、`reduced-motion`（静态首帧）。
- 视觉沿用各章识别色（ch01 indigo / ch02 cyan / ch03 pink / ch04 teal / ch05 amber），新增交互色统一走 `tokens.css`。

## 3. 逐章详细设计

### 第 1 章 · 数据（5 个）

**d01-1 数据加载 → 数据流水线动画**
- 原形式：控制台打印日志 + 前 10 行表格 + 字段映射表。
- 新形式：横向四格动画管道。点"加载 CSV"，几行原始字符串行（以一行为单位的卡片）依次流过 ①`d3.csvParse`（字符串→字段数组）② accessor（类型转换，`序号/年龄`变成数字徽章、`生日`变日期徽章）③ 重命名（中文列→`id/name/...`），每过一道机器卡片形态变化；类型不合法的单元标红并提示。
- 交互：播放/暂停/单步；可故意注入一行脏数据看它在哪一步被标红。
- 教学点：`d3.csv(url, row)` 的 `row` 转换函数在"每一行"上执行；类型不转换时字符串不能做算术。
- 技术：`d3.csv`、卡片用 transition 沿通道移动、`@keyframes` 辅助。
- 数据：真实 `newstudent.csv`。

**d01-2 DIKW → 数据精炼动画**
- 原形式：静态可点梯形金字塔。
- 新形式：底部 80 个散乱学生点（真实数据）；点"提炼"逐级发生：数据→统计量（点聚合成平均年龄、人数等"信息"条）→规律（点合成一条趋势/模式"知识"）→一个决策卡（"智慧"）。每级原始元素数量减少、抽象度升高，可用漏斗宽度或力导向聚拢表达。
- 交互：单步提炼；点击任一层显示"它回答什么问题、典型可视化是什么"。
- 教学点：金字塔不是背定义，而是"从原始记录逐步聚合抽象"的过程；越往上越接近决策。
- 技术：`d3-force` 聚拢 / 或 `d3-hierarchy` 层级聚合，transition。
- 数据：真实 `newstudent.csv`。

**d01-3 视觉通道 → 拖拽编码工作台**
- 原形式：4 张固定小图（类别→色相、序数→明度、数值→位置、数值→色相错配）。
- 新形式：左侧是字段卡（性别/班级/年龄/专业），右侧是通道槽（x 位置、y 位置、颜色、大小、形状）。把字段**拖进通道槽**，右侧图形实时重绘；右上角给一个"可读性评分"（顺序性是否被正确表达、类别是否可分、是否用了感知均匀的编码）。错配（数值→色相）时评分下降并说明原因。
- 交互：HTML5 拖拽 + 点击清除；可一键"让我看看最差/最佳编码"。
- 教学点：Mackinlay/Stevens 有效性排序——类别用色相、序数用明度、数值用位置；同一数据不同编码，可读性天差地别。
- 技术：HTML5 drag/drop、`d3.scaleOrdinal/Linear/Sequential`、评分用可解释的小规则。
- 数据：真实学生小样本。

**d01-4 数组函数 → 算子流水线**
- 原形式：下拉选函数 + 打印 JSON。
- 新形式：左侧数据集（一排方块/两列数据 A、B），中间是 10 个算子芯片（map/filter/reduce/group/rollup/cross/merge/pairs/transpose/zip）。点击算子把它**串进流水线**，数据以图形形态实时变化：`map` 方块按函数变高变色、`filter` 不符合的方块淡出、`group/rollup` 方块被收进带标签的容器、`cross` 两列间连配对线（二分图）、`pairs` 相邻连线、`transpose` 行列翻转、`zip` 对位配对。
- 交互：可串多个算子看累积结果；撤销/重置；悬停看该算子签名。
- 教学点：每个变换"改变数据形状"的直观含义；`group` 保留元素、`rollup` 聚合为一个值的区别。
- 技术：D3 join + 连线生成（`d3.line`/手动 path）、简单状态机。
- 数据：小的内置示例数组 + 真实学生数据（group/rollup 用）。

**d01-5 Data-Join → 数据↔DOM 配对连线**
- 原形式：一排圆点 enter/update/exit（绿/蓝/红）。
- 新形式：左列数据卡片（带 key），右列 DOM 柱，中间连线。增/删/改/重排时，中间连线重连：新增=绿色虚线（enter）、已存在=蓝色实线并随 key 保持身份（update）、删除=红色淡出（exit）。提供"有 key 函数 / 无 key（按索引）"开关，重排时直观看到**无 key 会导致元素身份错乱、过渡张冠李戴**。
- 交互：增/删/改/洗牌/重置；切换 key 开关。
- 教学点：join 的本质是"数据与图形的匹配"；`key function` 决定对象恒等，这是原站没讲透的点。
- 技术：D3 join 三态 + 手动连线 + transition。
- 数据：小内置数组。

### 第 2 章 · 数据可视化流程（4 个）

**d02-1 管道模型 → 端到端联动沙盘**
- 原形式：5 节点静态水平流程图，点节点显示 Card/Mackinlay/van Wijk 文字。
- 新形式：一条真实数据贯穿 5 个**联动小视图**：原始数据散点 → 数据变换（可加 filter 条件、点数随之变化）→ 视觉映射（选 x/y 字段，点落到坐标）→ 视图渲染（可缩放/平移）→ 用户交互（刷选高亮，高亮回传到前序视图）。三个理论作为"透镜"开关，叠加在对应阶段上标注。
- 交互：每阶段都可操作且上下游联动；刷选反向高亮。
- 教学点：参考模型不是名词背诵，而是你亲手驱动的管线；交互会反向影响前序视图。
- 技术：多个小 SVG 联动、`d3-brush`、`d3-zoom`。
- 数据：真实学生数据。

**d02-2 rollup 分组聚合 → 点聚簇 + 树图/马赛克**
- 原形式：3 个下拉 + 纯文本打印嵌套 Map 树。
- 新形式：80 个学生点先散开；选分组维度（专业/班级/性别…）后点**动态聚簇**，再以面积编码聚合结果，可在三种视图间切换：**矩形树图 treemap / 马赛克图 marimekko / 打包圆 pack**。聚合方式（计数/均值/比例）切换时面积重算。悬停看组内明细。
- 交互：维度下拉、聚合方式、三种布局切换、下钻。
- 教学点：`d3.rollup` 多级聚合的结果是"层次 + 数值"，面积比嵌套 Map 文本易读；层级数据的三种面积表达。
- 技术：`d3.rollup/groups`、`d3-hierarchy` 的 `treemap/pack`、马赛克用堆叠计算。
- 数据：真实 `newstudent.csv`。

**d02-3 树布局 → 算法分步构建 + 三态对比**
- 原形式：水平 Reingold-Tilford 树（层级下拉 + separation 滑块）。
- 新形式：选定层级后，**逐步播放算法**：节点初始重叠 → 后序计算子树宽度 → 第一次遍历定位 → 第二次遍历消除重叠 → 均匀排开。可一键对比水平 / 垂直 / 放射（radial）三种布局，保留 separation 调节。
- 交互：单步/播放、布局切换、separation 滑块。
- 教学点：树布局是一种"算法"而非自动魔法；放射布局如何映射角度。
- 技术：`d3.tree/cluster`、`d3.hierarchy`、radial 用角度映射、transition。
- 数据：真实学生 rollup 层次。

**d02-4 树形列表/事件委托 → 事件冒泡路径动画**
- 原形式：HTML ul/li 折叠树 + 动画时长滑块 + 全展开/折叠。
- 新形式：同样有可折叠 DOM 树（教学需要），但核心是**点击叶子节点时，事件沿 DOM 树自底向上逐层冒泡，路径高亮动画**，并显示被哪一层捕获/`stopPropagation` 截断。切换"每节点单独监听 vs 根节点事件委托"，顶部计数器显示绑定的监听器数量（N 个 vs 1 个）。
- 交互：点叶子、切换委托模式、设置阻断层。
- 教学点：捕获/目标/冒泡三阶段；事件委托为何只需 1 个监听器且对动态元素有效；`stopPropagation` 的影响。
- 技术：DOM 折叠树 + 事件委托 + 沿祖先链高亮 + transition。
- 数据：真实学生层次（专业→班级→学生）。

### 第 3 章 · 色彩专题（8 个）

> 色彩章是"换形式"重点：原站大量是竖条、色板、像素点阵、卡片投票。新版围绕"色轮几何、感知诊断、量化对比、动手修复"重做。

**d03-1 颜色模型 → 颜色空间几何实验室**
- 原形式：RGB 三滑块 + 4 个同色方块 + 3 个 CVD 小色块。
- 新形式：并排展示 RGB 立方体（正交三面投影）、HSL 圆柱展开、Lab a*b* 切片，**同一个颜色点在三个空间里同步定位**；可在 RGB 空间取"等距"的一组点，切到 Lab 看它们距离不等、且 RGB 里等距球在 Lab 里是变形体（直观说明感知非均匀）。
- 交互：拖点/取色，三空间联动；按钮"生成 RGB 等距环"。
- 教学点：颜色只是坐标；RGB/HSL 不感知均匀，Lab 距离≈感知差。
- 技术：`d3-color`（rgb/hsl/lab）、2D 投影、`d3.interpolateLab`。
- 数据：内置。

**d03-2 colormap 三类 → 配色诊断工作台**
- 原形式：决策表 + 色条 + 谋杀率竖条（Viridis 对 / RdBu 错）。
- 新形式：同一份真实数据（犯罪率/温度）一张图，下拉尝试 顺序/发散/定性/错误 jet 配色；下方**联动三条诊断曲线**：① 感知亮度沿色条是否单调（好的顺序色应单调）② 局部梯度（jet 会出现假峰/假边界）③ CVD 模拟后相邻色可分性。
- 交互：换 colormap、换数据、悬停定位假边界。
- 教学点：为什么有序数据必须用顺序色、发散色要锚定有意义的中点；jet 的假边界问题。
- 技术：`d3-scale-chromatic`、`d3.color` 亮度计算、CVD 矩阵（复用原站）、linked views。
- 数据：真实 `crime.csv` / `weather_2024.csv`。

**d03-3 Lab 色域 → 三色域边界叠加 + 裁剪轨迹**
- 原形式：单一 sRGB 的 a*b* 像素点阵（L 滑块）。
- 新形式：保留 a*b* 平面，叠加 **sRGB / Adobe RGB / Rec.2020 三个色域边界（近似多边形）**，L* 变化时三者实时缩放；点选一个色域外颜色，显示它被 clamp 回 sRGB 的轨迹和色差 ΔE。
- 交互：L* 滑块、点平面选色、切换色域。
- 教学点：色域有大小；超色域颜色会被裁剪导致失真；Lab 是设计感知线性 colormap 的工作空间。
- 技术：`d3.lab`、色域近似边界（内置顶点数据）、逐点栅格、ΔE 近似。
- 数据：内置。

**d03-4 色系搭配 → 交互式色轮和谐器**
- 原形式：5 张色板卡片 + 假论文柱（H 滑块）。
- 新形式：一个**可旋转 HSL 色轮**，拖主色后，和谐规则（单色/类比/互补/三等分/分裂互补）在色轮上**实时画出几何关系**（互补=过圆心直径、类比=相邻扇形、三等分=内接等边三角形、分裂互补=Y 形），下方色板与一张真实多类图同步。
- 交互：旋转主色、切换规则、应用到真实图表。
- 教学点：5 种和谐规则的几何本质与适用场景。
- 技术：极坐标绘制色轮、几何关系 overlay、`d3.hsl`。
- 数据：真实学生类别图。

**d03-5 经典配色 → 真实图表 A/B 量化对比**
- 原形式：9 套色板横评矩阵 + 假柱/折线 tab。
- 新形式：同一张**真实多类别散点**图，切换 Wong/Okabe-Ito/Tol/Tableau/Paired 等方案，实时叠加 **CVD 滤镜与灰度滤镜**，并给出量化指标（相邻类别最小色差、CVD 后最小色差、灰度后是否仍可分），用条形显示各方案得分。
- 交互：选配色、切滤镜、按指标排序。
- 教学点：三大科研黄金标准为何胜出；类别数 ≤ 7；连续色不能当离散用。
- 技术：`d3-scale-chromatic`、色差计算、CVD 矩阵、灰度转换。
- 数据：真实学生散点。

**d03-6 对错案例 → 配色找茬闯关**
- 原形式：4 张卡片点选投票。
- 新形式：连续若干"有问题的图"（jet 热力图、红绿对比、颜色过多、亮度倒挂、强调色用错），学生**点击图中问题区域并选择问题类型**；答对后该区域高亮并解释，可一键"修复"，做前后对比。计分与进度。
- 交互：点区域、选问题、修复、下一关。
- 教学点：常见配色坑的识别与修法，比投票更主动、覆盖更全。
- 技术：热点区域 + 判定 + 修复前后 transition、轻量计分。
- 数据：内置 + 真实犯罪/天气。

**d03-7 鲜艳/低饱和 → 仪表板上色 + 对比度检测**
- 原形式：HSL 滑块生成 7 色板 + 假论文卡片。
- 新形式：调主色后，给一个**多面板示例仪表板（柱/线/区域/标注文字）**整体上色，基于"鲜艳+低饱和"原则生成配套色；实时检查 WCAG 文字对比、相邻块色差、饱和度分布，并在"全饱和↔低饱和"滑动时对比耐看度。
- 交互：主色/饱和度滑块、一键应用、查看不达标项。
- 教学点：主色鲜明、配套低饱和、强调色不全饱和、文字对比达标。
- 技术：HSL 派生、WCAG 相对亮度、`d3.color`。
- 数据：内置仪表板。

**d03-8 CVD → 实时滤镜 + 冗余编码修复**
- 原形式：3 张图 × 3 视觉静态小图。
- 新形式：上方一张真实多类图，切换 正常/红色盲/绿色盲/蓝色盲/灰度**实时滤镜**；当发现红绿不可分时，逐步"添加形状标记 / 直接标注 / 纹理填充 / 改用 Wong 色"，观察在滤镜下重新可分。
- 交互：切滤镜、逐项加冗余、对比。
- 教学点：不能只靠颜色编码；冗余通道（形状/标签/纹理）是可访问性的正解；实测流程。
- 技术：CVD 矩阵、symbol shapes、SVG pattern、实时重绘。
- 数据：真实学生散点。

### 第 4 章 · 低维数据可视化（5 个）

**d04-1 宽/长格式 → 表格单元飞行 morph**
- 原形式：宽/长 JSON 文本 + 前 10 行表格。
- 新形式：宽表（州 × 指标网格）与长表（州, 指标, 值）两视图；点"reshape"，每个宽表单元格**沿动画飞散、重组成长表三元组行**（反向亦可），过程中可见数据单元数量守恒、只是重排。
- 交互：宽↔长双向 morph、播放/单步、高亮某州跟踪它的所有单元。
- 教学点：tidy data 三原则；melt/cast 是单元重排，不增不减。
- 技术：自定义 FLIP/位置插值动画、`flatMap` 映射。
- 数据：真实 `crime.csv`。

**d04-2 三层坐标变换 → 三层映射器 + 网格变形**
- 原形式：单散点（谋杀 vs 抢劫）+ linear/log/sqrt 单选。
- 新形式：并排三个区域（数据域 → 归一化坐标 → 屏幕像素），点在三层间用连线对应；切 linear/log/sqrt 时，**坐标网格被拉伸/压缩的变形动画**，右偏数据被"拉直"；多个真实数据点联动。
- 交互：拖一个点看三层位置、切尺度、开关网格。
- 教学点：scale 是数据↔像素的函数；margin 是坐标系→屏幕的偏移；对数/开方何时用。
- 技术：`scaleLinear/Log/Sqrt`、网格变形、跨层连线。
- 数据：真实 `crime.csv`。

**d04-3 曲线拟合 → 小倍数网格 + 过冲标注**
- 原形式：10 种 curve tab 逐个切换、单图。
- 新形式：同一数据，**10 格小倍数同屏铺开**（linear/monotone/natural/basis/cardinal/catmullRom/step×3/bundle）；每格标注是否穿过数据点、是否过冲（overshoot）；hover 放大，拖一个控制点时所有曲线联动反应。
- 交互：小倍数 hover 聚焦、拖控制点、排序（按过冲大小）。
- 教学点：小倍数便于横向比较；插值过所有点但易过冲，拟合只看趋势；monotoneX 保单调。
- 技术：`d3.line().curve(...)`、10 子图、拖拽。
- 数据：真实 `crime.csv`（人口 vs 谋杀）。

**d04-4 倾角感知 → 斜率判读小实验**
- 原形式：单条线 + 角度滑块（45° 参考）。
- 新形式：一个**迷你心理物理实验**：每轮出现一对/几组线段，学生判断"哪条更陡"或"估计比值"，系统记录判断误差；若干轮后自动绘制学生自己的 **判断误差 vs 倾角曲线**，重现"45° 附近最准"。附"纵横比调节"，拖动改变 aspect ratio 让关键斜率逼近 45°。
- 交互：多轮作答、实时生成误差曲线、调纵横比。
- 教学点：人眼对斜率感知非线性，45° 最准；设计图应让关键斜率落在 30–60°，指数趋势用 log 轴。
- 技术：随机出题、记录回答、`d3.line` 画误差曲线。
- 数据：学生实验自产数据。

**d04-5 Marching Squares → 逐格算法动画 + 鼠标塑形**
- 原形式：8×8 网格 + 阈值滑块出等值线。
- 新形式：**逐格播放**：当前 cell 高亮、4 角二值化、16 种 case 编号点亮、等值线段逐条画出（含最近邻 vs 线性插值对比）；可**直接在画布上拖动鼠标改变标量场高度**，等值线实时跟随。
- 交互：单步/播放、阈值滑块、鼠标塑形、插值方式切换。
- 教学点：16 种 case 如何决定线段；线性插值让线更准；扩展到 3D 即 Marching Cubes；应用于等高线/密度图/MRI。
- 技术：raster 网格、case 查表、线性插值、d3-contour 对照、鼠标改值。
- 数据：内置高斯场（可塑形）+ `crime.csv` 密度图作为真实应用。

## 4. 与原站的形式差异（对照说明）

- **静态图 → 过程动画**：数据加载、DIKW、宽长转换、树布局、等值线、事件冒泡——都改成"逐步播放算法/数据变化"。
- **文本控制台 → 图形**：rollup（文本 Map）→ 树图/马赛克；数组函数（JSON）→ 方块/连线算子图；宽长（JSON）→ 单元 morph。
- **固定图 → 可搭建/可实验**：视觉通道（4 张死图）→ 拖拽编码工作台；颜色模型（滑块色块）→ 颜色空间几何；倾角（看一条线）→ 自己做实验产出误差曲线。
- **单图切换 → 小倍数同屏对比**：10 种曲线、多日历布局、配色方案。
- **点选卡片 → 游戏化/主动诊断**：对错案例（投票）→ 找茬闯关；时间属性（点卡片）→ 场景拖拽分类；CVD（看静态结果）→ 实时滤镜并动手修复。
- **原站没有的图种**：桑基/alluvial、treemap、pack 圆、马赛克、力导向聚簇、真正的 HSL 色轮、brush 联动、算法分步、二分配对连线、心理物理实验、可塑形标量场。
- **保留但换骨**：日历热图、螺旋、Storyline、折叠树这些"教学点本身就是它"的图保留，改交互与对比方式，不做无意义替换。
