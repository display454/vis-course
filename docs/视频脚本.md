## 00:23—00:48  学习结构 · 原理、代码、效果就地对照

画面：`chapter.html?c=01`

首先是学习路径。每个小节都采用一致的讲解、关键代码、演示三视图。先读原理，再查看有注释的实现，最后操作对应图形，不必在多个页面之间来回寻找。侧栏始终保留章节位置和学习进度。界面也统一了标题层级、卡片间距和章节配色，让教学内容成为视觉重点。

操作顺序：code → demo → pipeline

## 00:48—01:13  色彩改进 · 发现问题，再亲手修复

画面：`chapter.html?c=03`，`d03-8`

第一个重点，是色彩章的可访问性实验。正常视图中，红色和绿色看起来很容易区分。切换到灰度后，两类颜色的差别明显缩小，单靠颜色就容易丢失信息。接着加入形状标记和文字标签，即使颜色接近，类别仍然可以辨认。改进的价值，是把配色原则变成一次可以验证、也可以修复的实验。

操作顺序：gray → shape → labels → wong

## 01:13—01:37  曲线改进 · 十种算法，同屏联动比较

画面：`chapter.html?c=04`，`d04-3`

第二个重点，是低维数据章的曲线比较。这里把十种曲线放在同一屏里，使用完全相同的一组数据点。拖动上方的控制点，所有曲线会同步变化。有的穿过数据点，有的只表达整体趋势，部分曲线还会产生过冲。学生因此能比较不同算法的行为，而不是只记住函数名称。

操作顺序：curveDrag → curveDragBack → curveSort

## 01:37—02:02  算法改进 · 把等值线拆成可观察的步骤

画面：`chapter.html?c=04`，`d04-5`

第三个例子，是等值线算法。点击下一格，可以看到当前网格的四个角怎样根据阈值分类，再通过查表生成线段。播放能连续观察这个过程。随后在画布上拖动，直接改变标量场，等值线也会重新计算。最后切换中点近似与线性插值，对比定位差异，让算法步骤和最终结果联系起来。

操作顺序：step → step → play → sculpt → nearest → linear

## 02:02—02:27  时序改进 · 一份数据，三个观察角度

画面：`chapter.html?c=05`，`d05-3`

第四个重点，是同一份气象数据的多视图比较。年历适合观察全年变化，十二个月的小倍数便于比较月份，星期乘月份的布局则把重复的星期关系汇总出来。还可以切换气温与降雨指标。这里强调的是，不同图形回答不同问题；数据不变，换一种组织方式，就可能看见另一种规律。

操作顺序：months → cycle → rain → temp

## 02:27—02:54  叙事改进 · 故事线与阶段流转相互对照

画面：`chapter.html?c=05`，`d05-5`

最后看故事线。每条曲线代表一名角色，横轴是时间，线条的靠近用来表达角色相遇。点击事件点，可以结合剧情理解关系变化。左侧标签允许调整角色位置，辅助观察。切换到阶段流转视图后，重点变为角色在哪些幕中出现。两种视图放在一起，帮助学生理解连续关系和离散阶段表达的区别。

操作顺序：event → laneDrag → alluvial → story
