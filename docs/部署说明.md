## 方式一：网页上传（最简单，推荐第一次使用）

1. 登录 GitHub，点右上角 **+ → New repository**，新建一个公开仓库，例如 `vis`。
2. 进入该仓库，点 **Add file → Upload files**。
3. 把 `vis-site` 文件夹**里面的全部内容**（`index.html`、`chapter.html`、`assets/`、`data/`、`docs/`、`.nojekyll` 等）拖到网页上传区。
   - 注意：是上传文件夹**里面的内容**，让 `index.html` 位于仓库根目录，而不是套一层 `vis-site/` 目录。
   - `.nojekyll` 是隐藏文件（以点开头），务必一起上传；若网页上传看不到它，可在仓库 **Add file → Create new file**，文件名填 `.nojekyll`，内容留空，提交即可。
4. 点 **Commit changes**。
5. 打开仓库 **Settings → Pages**：
   - **Source** 选 `Deploy from a branch`；
   - **Branch** 选 `main`、目录选 `/ (root)`，点 **Save**。
6. 等待约 1 分钟，刷新 Pages 页面，会出现发布地址，形如：
   `https://<你的用户名>.github.io/vis/`
   打开即为你的网站。

## 方式二：Git 命令行

```bash
# 1. 在 vis-site 文件夹内初始化（确认 index.html 就在当前目录）
git init
git add .
git commit -m "重构可视化导论课程网站"

# 2. 在 GitHub 新建空仓库 vis 后，关联并推送（把 <用户名> 换成你的）
git branch -M main
git remote add origin https://github.com/<用户名>/vis.git
git push -u origin main
```

然后到仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，保存。稍等片刻访问 `https://<用户名>.github.io/vis/`。

## 常见问题

- **打开是 404 / 一片空白**
  - 确认仓库根目录直接就是 `index.html`（不要多套一层文件夹）。
  - 确认 Pages 的目录选的是 `/ (root)`，且已等待 1–2 分钟。
- **部分脚本/数据 404**
  - 确认 `assets/`、`data/` 文件夹完整上传，文件名大小写与本地一致（GitHub 区分大小写）。
  - 确认 `.nojekyll` 已存在（避免 GitHub 误忽略以 `_` 开头的文件/目录）。
- **想要根域名 `https://<用户名>.github.io/`**
  - 把仓库命名为 `<用户名>.github.io`（用户页），其余步骤相同。
- **D3 图表不显示**
  - 网站需联网加载 `https://cdn.jsdelivr.net/npm/d3@7/+esm`；确认网络可访问 jsDelivr。
  - 本站用 ES Modules，**必须通过 http(s) 访问（即 GitHub Pages）**，不要直接双击 `file://` 打开。
- **本地预览**
  - 在 `vis-site` 目录执行：`python -m http.server 8123`，浏览器访问 `http://localhost:8123/`。
- **更新网站**
  - 重新上传/提交改动文件即可，Pages 会在约 1 分钟内自动更新；若没变化，强制刷新（Ctrl+F5）清缓存。
