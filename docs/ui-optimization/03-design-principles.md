# 03 · 可执行 UI 设计准则（含优先级评分）

> 每条准则回答：现状问题 → 参考案例 → 视觉/交互原理 → 迁移方式 → 具体 CSS/结构 → 验证方法。
> 优先级评分：视觉提升 V、交互收益 I、成本 C（越低越好）、风险 R（越低越好）、适配度 F（1–5），综合 P = V+I+F−C−R（0–15 量级，≥10 为高）。

## P0｜移动端可读性与可用性（最高优先）

**G1. 宽表格只横向滚动，绝不压缩成竖排单字**
- 问题：390px 下 `.tbl` 等宽列，中文逐字竖排（审计 P0-1）。
- 案例：Stripe Docs（窄屏数据表横向滚动）、Ant Design Table（`scroll.x`）。
- 原理：保留语义列宽与可读性，把"信息折损"换成"可滚动的操作"，方向明确。
- 迁移：给 `.tbl` 包 `.tbl-scroll`；演示表 `.vx-table.wrap` 已支持，统一到全部表格。
- CSS：`.tbl-scroll{overflow-x:auto;-webkit-overflow-scrolling:touch;margin:0 0 16px} .tbl-scroll .tbl{min-width:560px;margin:0}`。
- 验证：390 截 Stevens 表/速查表，列头与单元格不再逐字换行、可横向滑动且无页面级横滚。
- 评分：V4 I5 C1 R1 F5 → **P=12**

**G2. 三视图 Tab 在窄屏保留全部文字标签**
- 问题：≤440px 隐藏 `.label`，"关键代码/演示"只剩图标（P0-2）。
- 案例：Material 3（导航带文字）、Radix（图标按钮必须有可访问名）。
- 原理：三视图是本站核心导航，图标语义不可替代。
- 迁移：删掉 `@media(max-width:440px){.tab-btn .label{display:none}}`；窄屏改为图标在上、文字在下或缩小字号，三段等宽。
- CSS：`@media(max-width:640px){.tab-btn{flex-direction:column;gap:3px;padding:7px 4px;font-size:12px;min-height:48px}}`。
- 验证：390 下三个 Tab 都有文字且不溢出。
- 评分：V3 I5 C1 R1 F5 → **P=11**

**G3. 固定宽 SVG 演示在窄屏走横向滚动，不缩成小图**
- 问题：d03-1（1060 宽）等比缩到 ~100px 三面板（P0-3）。
- 案例：Stripe Docs（代码/宽内容横滚）、ECharts 示例（图保留最小可读宽）。
- 迁移：对 `W≥860` 的固定 viewBox 演示调用 `svg(d3,stage,W,H,{scrollMin})`；`scrollMin=Math.max(W,560)`。
- 验证：390 打开 d03-1，轴字/标签可读，容器内横滚，页面不整体横滚。
- 评分：V4 I4 C2 R1 F5 → **P=10**

**G4. 移动端可点控件 ≥44px 热区**
- 问题：`.vx-btn` 34px、select 32px（P0-4）。
- 案例：Material 3（48dp）、Stripe（44px）、Apple HIG（44pt）。
- 迁移：≤640 提升按钮/选择器/滑块高度；滑块轨道加宽到 28px 可点区。
- 验证：390 下用元素盒模型量 `min-height≥40`（次按钮 44），间距不重叠。
- 评分：V2 I5 C1 R1 F5 → **P=10**

## P1｜布局与比例

**G5. 讲义区分"阅读列"与"全宽图列"**
- 问题：段落限 66ch，但标题/表格/卡片时宽时窄（P2-13）。
- 案例：Distill（65ch 正文 + 侧栏图）、OWID（图可破列）。
- 原理：阅读行宽稳定保证舒适，图/表需要空间时可全宽。
- 迁移：`.lesson-content` 不设死宽；仅 `p,li` 入阅读列；`.codeblock/.tbl-scroll/.demo-card/.callout` 可到 `--figure-w`；演示视图不限宽。
- 验证：1440 章节页，正文右缘整齐，图表/代码可更宽，阅读不超过 66ch。
- 评分：V4 I4 C2 R2 F4 → **P=8**

**G6. 收紧知识地图卡留白，让图成为主体**
- 问题：卡内上下 ~100px 空白（P1-5）。
- 案例：ECharts 示例（图占卡主体）、Pudding（全宽图）。
- 迁移：`.map-wrap padding 24→20/16`；SVG 上下留白压缩；图例贴顶、提示贴底。
- 验证：1440/390 截图，地图节点垂直居中偏上，空区显著减少。
- 评分：V4 I2 C1 R1 F4 → **P=8**

**G7. bento 行内卡片等高、底缘对齐**
- 问题：第 4/5 张卡明显矮（P1-6）。
- 案例：Linear 卡片（同栅格 stretch）、Primer 网格。
- 迁移：`.ch-grid{align-items:stretch}`；`.ch-card` 用 flex 列，`.desc{flex:1}`、`进入章节`锚到底。
- 验证：1440 第二行两卡等高，链接在同一基线上。
- 评分：V3 I3 C1 R1 F5 → **P=9**

**G8. 区块节奏统一（眉标 + 标题 + 引导句）**
- 问题：03/04 区块缺引导句（P1-7），区块间距 88px 偏大（P1-8）。
- 案例：Linear（区块 96px 桌面，但头部结构一致）、Tailwind Docs。
- 迁移：所有区块头统一三行结构；桌面区块 88→80、移动 48；序号并入眉标。
- 验证：首页四个区块头部结构一致，全页高度下降且不局促。
- 评分：V3 I3 C1 R1 F4 → **P=8**

**G9. 文档侧栏在 ≤1024 折叠、桌面侧栏导航更稳**
- 问题：断点散乱（920 才折），1024 平板侧栏偏挤。
- 案例：Stripe/VitePress（<1024 抽屉）、Mintlify（260px 侧栏 + 3px 激活条）。
- 迁移：把章节侧栏单栏断点从 920 提到 1024；平板侧栏横向 chip 导航。
- 验证：1024/768 不出现被挤压的侧栏。
- 评分：V3 I4 C2 R2 F4 → **P=7**

## P2｜视觉规范与细节

**G10. 线性字阶 + 数字 tabular-nums + 负字距**
- 问题：标题与大数字字距未精修。
- 案例：Linear（负字距随字号收敛）、Geist（等宽数字）。
- 迁移：标题负字距 -0.02/-0.015em；`.hero-stats .n` 加 `font-variant-numeric:tabular-nums`；眉标正字距 +0.04–0.12em。
- 验证：大数字等宽、标题与正文层级分明。
- 评分：V3 I1 C1 R1 F5 → **P=7**

**G11. 面阶代替阴影，阴影只给真浮层**
- 问题：普通卡也有弱阴影，层级偏"平浮"。
- 案例：Linear（4 级面 + 发丝线）、Stripe（明度分层）。
- 迁移：普通卡 `box-shadow:none` + 发丝边；hover 卡与弹层才用 `--shadow`/`--shadow-lg`。
- 验证：页面更干净，浮层（检索框、hover 卡）仍明显浮起。
- 评分：V3 I2 C2 R2 F4 → **P=5**

**G12. 统一原生控件（range/select/输入）为章主色**
- 问题：滑块是系统默认（P2-11）。
- 案例：Carbon/Elastic（图表控件主题化）、Material（滑块状态）。
- 迁移：`accent-color:var(--acc)`（最省事且跨端），select 高度/聚焦态统一。
- 验证：d03-1 滑块呈现章主色，焦点环一致。
- 评分：V2 I3 C1 R1 F5 → **P=8**

**G13. 图表轴/网格/留白统一默认值**
- 问题：27 演示轴色已统一但 margin/隔项策略不一。
- 案例：Plot/Vega/Datawrapper。
- 迁移：轴字 11px mono `--ink-4`；网格 `rgba(20,27,38,.06)`；窄屏标签隔项/旋转；能直标不外挂图例。
- 验证：抽样 6 个演示，轴留白一致、窄屏不重叠。
- 评分：V3 I3 C3 R2 F4 → **P=5**

**G14. 组件五态齐备 + 焦点环统一**
- 问题：个别控件缺 active/focus 一致表现。
- 案例：shadcn、Material 3。
- 迁移：default/hover/focus-visible/active/disabled；`:active{translateY(1px)}`；focus `2px accent offset2`。
- 验证：键盘 Tab 遍历，焦点环在所有控件上可见且同色。
- 评分：V2 I4 C1 R1 F5 → **P=9**

**G15. Hero 图卡对比与注释安全边距**
- 问题：`.attr()` 注释偏淡、贴缘（P2-9）。
- 案例：Stripe 代码面板（注释对比足够）、Datawrapper（注释不贴边）。
- 迁移：注释不透明度 ↑、玻璃卡内边距 20px、柱体散点对比微调。
- 验证：1440/390 注释清晰可读、不贴边。
- 评分：V2 I2 C1 R1 F4 → **P=6**

**G16. 页脚与区块脚注移动端行高**
- 问题：移动 footer 末行贴边（P2-12）。
- 案例：Linear footer（64×32 内边距）。
- 迁移：移动端 footer 行高 1.8、底部 padding 28px，正文补数据来源行。
- 验证：390 底部无裁切/贴边。
- 评分：V1 I2 C1 R1 F4 → **P=5**

## 取舍说明
- 高优先级（≥10）：G1–G4、G7、G14——先做，集中解决移动端与等高/状态。
- 中优先级（7–9）：G5、G6、G8、G9、G10、G12——本轮完成。
- 低优先级（≤6）：G11、G13、G15、G16——以最小改动做或仅做安全项，避免过度设计。
- **不做**：不引入新依赖/新字体/新主色；不重排内容；不新增重交互；不加视频。
